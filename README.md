# 文特高峽谷（Soteska Vintgar）健行深度策展指南

> **地理位置**：斯洛維尼亞 • 特里格拉夫國家公園（鄰近布萊德湖 Lake Bled / 極東義大利與斯洛維尼亞邊境）  
> **核心特色**：翡翠碧綠激流、垂直崖壁懸空木棧道、百年鐵路石拱橋、斯拉姆大瀑布、高山牧野回程  
> **特色功能**：內建 Web Audio API 沉浸式擬真溪流環境音效（支援激流／潺潺流水／瀑布模式與鳥鳴）

---

## 🌲 健行五大核心觀看重點

| 編號 | 觀看重點 | 景點特徵與體驗精華 |
|:---|:---|:---|
| **01** | **翡翠綠拉多夫納河（Radovna River）** | 水源源自阿爾卑斯融雪，富含石灰岩礦物呈現極清澈綠松石色；野生褐鱒悠游、石灰岩壺穴激流。 |
| **02** | **懸空崖壁木棧道（Žumrovka）** | 始建於1893年，懸空架設於垂直岩壁，近距離感受轟鳴急流與沁涼水霧，體驗「一線天」峽谷視野。 |
| **03** | **博希尼鐵路百年石拱橋（1906）** | 跨越峽谷上方 33.5 公尺高的全石砌單孔拱橋，為奧匈帝國連接中歐與亞得里亞海之代表工藝。 |
| **04** | **斯拉姆瀑布（Slap Šum, 13m）** | 峽谷步道終點，斯洛維尼亞最大的河流落差瀑布之一，午後常有陽光折射出的雙道彩虹。 |
| **05** | **聖凱薩琳教堂草原回程（Sv. Katarina）** | 單向出口後經紅線步道爬升至高山草甸，遠眺布萊德盆地、阿爾卑斯牧牛群與石造古教堂。 |

## 🥾 實用健行攻略須知

1. **單向通行規定（One-Way System）**：
   - 峽谷內部為單向管制（入口 ➔ 瀑布出口，約 1.6 km / 45 分鐘）。
   - 出口後回程可選：
     - **紅線（經聖凱薩琳教堂 Sv. Katarina）**：約 5.7 km / 1.5~2 小時，視野開闊最推薦。
     - **綠線（經山林小徑 Blejska Dobrava）**：約 4.3 km / 1 小時，林蔭遮蔽快。
2. **強制配戴安全頭盔**：入口驗票處免費發放安全頭盔與衛生網帽（防範偶發落石），出口處回收。
3. **最佳造訪時間**：
   - **晨間 08:00 - 09:30**（首梯進場，避開團客、享受晨霧與林間穿透光）。
   - **午後 15:30 - 17:00**（斜射光打在岩壁與綠水上，瀑布易見彩虹）。
4. **裝備建議**：防滑抓地健行鞋、防風防潑水外套（峽谷內均溫較外圍低 3~5°C）。

## 🎧 沉浸式互動網頁使用方式

直接使用瀏覽器開啟專案目錄下的 `index.html` 即可：
- 點擊右下角懸浮按鈕或頁面中的「🔊 聆聽峽谷水聲」，即時播放高擬真白噪音水流聲。
- 支援「湍急激流」、「清泉潺潺」、「瀑布轟鳴」三種音效頻譜切換及音量控制。
